## 研究的共同结论（→ 已写入 PRD-001）

1. **学习内容的最大缺口是 phonics**：现在只教字母名；澳洲 Foundation 课程要求字母最常见的音、口头拼读 / 拆音和 CVC 单词。→ P0
2. **"AI" 的最佳切入点不是聊天机器人**，而是：按技能的自适应（Elo / BKT）、间隔复习、家长掌握地图、离线生成并人工审核的个性化故事。→ P1
3. **5 岁孩子不应和 LLM 自由对话**；儿童语音识别准确率低；隐私上"不收集"是最强优势。→ 原则
4. **兴趣驱动**：交通工具、恐龙、动物 / 家庭生活、搭建、儿歌最受欢迎；让孩子在 2–4 个主题里选；主题要和知识点深度结合，答题区保持简洁。→ 主题世界
5. **奖励与健康**：奖励做成"惊喜"而不是"集齐"；每次 10–15 分钟，每天屏幕总时长 ≤ 1 小时；鼓励家长陪玩与线下延伸。→ P1
6. **入学标准**（第二轮，04）：最低 = AEDC on track + 能完成 Best Start 基础任务；最高 = NESA ES1 年末；NSW 官方不要求入学前会读写。→ PRD §8.1
7. **全学科**（第二轮，05）：英文数学之后先做口语和 Kindy Ready（情绪、自控、学校日常），再做科学；动作、社交、手写以线下为主。→ PRD §8.2
