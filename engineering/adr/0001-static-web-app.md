# 0001 用纯静态网页实现第一版
- 状态：已采纳
- 日期：2026-10-27

## 背景
第一个用户是一个 5 岁孩子，主要设备是 iPad。需要尽快可玩、零成本、零隐私风险。

## 决定
纯 HTML/CSS/JS，无框架、无构建步骤；进度存 localStorage；语音用浏览器 Web Speech API；GitHub Pages 托管。

## 后果
- 好：任何浏览器打开即玩；可"添加到主屏幕"；不收集任何数据，合规负担最小。
- 代价：进度不能跨设备；系统 TTS 音色因设备而异、无法准确发出 phonics 音（v0.2 用录音解决）；代码规模变大后需要模块化。
