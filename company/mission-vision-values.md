# 使命 · 愿景 · 价值观

> 状态：草案 v0.1（项目启动期，随产品验证迭代）

## 使命 Mission
让每个孩子都**带着自信和好奇心走进小学第一天**。

## 愿景 Vision
成为家长最信任的入学准备伙伴：一个孩子爱玩、老师认可、家长放心的学习世界。
从一个孩子（Ethan）开始，先把一个孩子服务到极致，再服务更多家庭。

## 价值观 Values
1. **孩子优先（Child first）**：先问"对孩子好吗"，再问"对增长好吗"。不做广告、不做诱导付费、不做上瘾设计。
2. **有证据的乐趣（Evidence-based fun）**：好玩是手段，学会是目的。每个功能都要说明它对应的学习目标和证据。
3. **家长是搭档（Parents as partners）**：透明地展示孩子学了什么，鼓励家长陪玩，把学习延伸到生活。
4. **隐私默认（Private by default）**：能在设备上完成的就不上传；必须收集的数据最少化，并获得家长同意。
5. **小步快跑（Ship small, learn fast）**：每周都让真实的孩子玩到新东西，用观察而不是猜测做决定。
