## 1. 背景与问题

**背景**：Ethan 5 岁，住在 Sydney（NSW），2027 年入读一所 NSW 公立小学的 **Kindergarten**（NSW 的 Kindergarten 就是小学第一年，相当于其他州的 Foundation / Prep），计划从 **Year 3 转入私立学校**。v0.1 已在 2026-10-27 上线：16 个语音引导小游戏（英文 8、数学 8），3 级自适应，星星 + 贴纸奖励，家长面板，部署在 GitHub Pages。

**Ethan 目前的情况**（2026-10，家长提供）：
- 上过两个学期 *I Can Read* 阅读课，**认读走在书写前面**（"看读阶段"）。
- 之前还没开始写字母，**最近开始主动写字母和数字，兴趣很高** → 书写类游戏优先级提高。
- 学校用哪套 phonics 教材还不确定。

**产品原则：不追求一次做完美，跟着 Ethan 一起成长**——每个学期根据他的实际进度和兴趣调整（见 §12.1 成长路线）。

**要解决的问题**

| # | 问题 | 依据 |
|---|---|---|
| P1 | 澳洲学校按 **synthetic phonics** 教阅读（字母音 → 拼读 → CVC 单词），v0.1 只教**字母名**，与学校衔接不上 | [R2] 摘要 1、差距清单 #1–#5 |
| P2 | 难度只按"一局正确率"升降，**不记得具体哪个字母 / 数字不会**，也没有跨天复习 | [R1] 摘要 1、[R2] 差距 #6 |
| P3 | 卡住时只能无限"再试一次"，缺少**逐级提示** | [R2] 差距 #7 |
| P4 | 内容是通用的，**没有利用孩子的强烈兴趣**（恐龙、交通工具……） | [R3] 摘要 1–2 |
| P5 | 没有**使用时长**保护；奖励偏"集齐全部"，存在削弱内在动机的风险 | [R2] 摘要 5–6、[R3-S25] |
| P6 | 家长看到的是"每个游戏几级"，而不是"孩子会了哪些入学技能" | [R2] 差距 #16 |

## 2. 产品愿景与定位

**愿景**：让每个孩子带着自信和好奇心走进小学第一天（详见 [`vision.md`](../vision.md)）。

**定位**：面向 4–6 岁、即将入读澳洲 Foundation 的孩子，**对齐澳洲课程、语音优先、无广告、数据不离开设备**的入学准备游戏。

## 3. 目标用户

> **当前定位（2026-10-28 家长确认）**：家庭自用，只服务 Ethan 一个孩子。App 要根据他的练习结果**自动分析、生成报告，并针对性地调整练习**（见 F-30、F-31）。是否开放给其他家庭，入学后再决定。

### 3.1 主要用户：孩子（Ethan 型）
- 5 岁，**还不识字**，能听懂英文指令；用 iPad / 手机触屏。
- 注意力短（单次 10–15 分钟），喜欢惊喜、被表扬、"属于我的"东西 [R3-S22]。
- 可能有强烈的主题兴趣（交通工具、恐龙等），这在 4–6 岁很常见，男孩中更常见 [R3-S1]；**但主题由孩子自己选，不按性别预设** [R3-S7][R3-S8]。
- 答错容易沮丧；需要温柔、具体的下一步。

### 3.2 购买 / 管理者：家长
- 希望孩子做好入学准备，但担心屏幕时间和广告。
- 想知道"孩子具体会了什么、还差什么、我能在生活中做什么"。
- 可能是双语家庭，家长界面需要中英双语（*假设：基于本项目创始人的情况，待验证*）。

### 3.3 未来用户（v1.0 以后，不在本期范围）
- 其他即将入学的家庭（朋友圈试玩 → 公开发布）。
- Foundation 老师（推荐给家长、布置家庭练习）。

## 4. 目标与非目标

### 目标（到 2027-01 底，Ethan 入学前）
1. **G1 学习**：以 **§8.1 入学标准**为准——英文和数学**所有行达到"最低"、主要行达到"典型"**；有余力的行逐步接近"最高"（= NSW Kindergarten 年末 ES1 水平），**不超出 ES1**，以免与学校的 phonics 顺序冲突。
2. **G1b 全人准备**：入学前完成 "Kindy Ready" 学校日常与情绪自控准备（§8.2），因为头几周的适应比学业更重要 [R5-S18]。
2. **G2 投入**：孩子每周 ≥ 5 天主动要玩，每次 10–15 分钟。
3. **G3 家长信任**：家长能在 1 分钟内看懂孩子掌握了哪些技能、下一步练什么。
4. **G4 安全健康**：零广告、零数据外传、每日时长保护。

### 非目标（本期明确不做）
- ❌ 孩子与 AI 实时对话 / AI 陪伴角色（风险高、证据弱，[R1] 摘要 3）。
- ~~账号、云同步、多设备进度~~ → **已改为需求**（家长 2026-10-28 要求电脑、iPad、手机同步），见 F-70 与 ADR-0003。
- ❌ 付费、订阅、广告。
- ❌ 原生 App 上架（先做 PWA）。
- ❌ 3 岁以下或 Year 1 以上的内容。

## 5. 成功指标

> 原则：**不为了指标收集孩子的数据**。指标来自设备本地的家长面板 + 家长试玩记录（`research/user-research/`）。

| 类型 | 指标 | 目标（2027-01） | 怎么测 |
|---|---|---|---|
| 入学标准 | §8.1 两张标准表的达成度 | 所有行 ≥ 最低；≥ 70% 的行 ≥ 典型 | F-60 家长清单 + 入学体检（每 4–6 周一次） |
| ⭐ 北极星 | **每周"有进步的学习天数"**：当天玩过且至少一项技能掌握度上升 | ≥ 4 天 / 周 | 家长面板（v0.3 起由学习者模型计算） |
| 学习 | 字母音掌握（26 个） | ≥ 20 个"已掌握" | 掌握地图 + 家长线下抽查 |
| 学习 | 能拼读 CVC 单词 | 能读出 ≥ 15 个 | 家长线下抽查 |
| 学习 | 数学技能 M1–M7 | 全部"已掌握" | 掌握地图 |
| 投入 | 每周游玩天数 | ≥ 5 天 | 家长面板"最近 7 天" |
| 投入 | 孩子主动要求玩的比例 | ≥ 50% | 试玩记录 |
| 体验 | 一次答对率 | 稳定在 65–85%（太低会沮丧，太高说明太简单） | 学习者模型；目标值参考 [R1-S37] |
| 护栏 | 单日使用时长 | 中位数 ≤ 20 分钟，且从不超过家长设定上限 | 家长面板 |
| 护栏 | 沮丧事件（连续 3 次答错后离开） | 每周 ≤ 1 次 | 本地记录 + 试玩记录 |
| 质量 | 冒烟测试 | 每次发布 100% 通过 | CI |

### 6.2 P0 —— v0.2「Phonics Foundations」

**F-20 Letter Sounds（字母音）** · E3 · P0 · ✅ 已上线（v0.2-alpha）
- *用户故事*：作为孩子，我听到 "s says /s/, sun"，并能听音找到对应字母，这样我能跟上学校的 phonics 课。
- *要点*：系统 TTS 读不准单个音素 [R1] TTS 补充、[R2] 差距 #1 → 使用**真人录音**（家长或配音员，澳洲口音），每个音 1 个 mp3（约 30–40 个文件，含 sh/ch/th/ng/qu 等可后续追加）。
- *玩法*：探索模式（点字母听音）+ 测验（听音选字母，2–4 个选项）。
- *验收*：26 个字母都有录音；录音缺失时自动回退到"字母名 + 例词"且不报错；冒烟测试覆盖。
- *实现（2026-10-28）*：研究环境无法下载开放许可的音素录音（Wikimedia 等被网络策略阻止），因此采用**家长录音**：家长页"字母音录音"为每个字母录 1.5 秒纯音，保存在设备 IndexedDB，不上传；没录的字母用设备语音的近似读音。好处：口音与家庭一致，可以按学校的发音习惯重录。后续如果找到合适的开放许可录音（或请配音员），可以作为默认音频加入。

**F-21 First Sound 音素版** · E5 · P0
- 把 First Letter 从"哪个字母"改为音素："/d/ … dog starts with /d/"。修正不规范例词（I→igloo/insect，X 的 fox 移出首音题）[R2] 差距 #4。
- *验收*：首音题库只包含首音是该字母"最常见音"的单词。

**F-22 Sound Blender（口头拼读）** · E6 · P0
- 听 "/c/ – /a/ – /t/"，从 3 张图片中选出 cat；L1 两个音（at, in），L2 三个音 CVC，L3 加速 / 去掉停顿提示。
- *验收*：至少 40 个 CVC 单词有图（emoji）+ 分段录音（可由单音录音拼接）。

**F-23 分组字母顺序** · E1–E3 · P0
- 按 synthetic phonics 惯例分组解锁：s a t p i n → m d g o c k → e u r → h b f l → j v w x y z qu（[R2] §1，行业惯例，**需与学校确认**）。
- 已学组 + 当前组出题；ABC Explorer 仍可自由浏览全部字母。

**F-24 Sight Words 拆分** · E8 · P0
- 拆为 **可拼读词**（am, at, it, in, on, can, up, big, mum, dad）→ 进拼读游戏；**tricky words**（I, the, to, go, no, my, he, she, we, me, you, was）→ 整词认读 [R2] 差距 #5。

**F-25 Quick Look（subitising）** · M3 · P0
- 点阵 / 骰子 / 十格图闪现 1–2 秒后隐藏，问 "How many?"；L1 1–3，L2 1–5，L3 5–10（十格结构）[R2] 差距 #8。

**F-26 逐级提示（Graduated hints）** · 全部 · P0
- 第 1 次错：重播题目；第 2 次错：放慢 + 高亮 / 缩小选项；第 3 次错：Dino 示范正确答案，孩子再点一次（这一题不计"一次答对"）[R2] 差距 #7。
- *验收*：任何题目都不会出现无限试错；孩子不会听到"wrong / fail"。

**F-28 家长教学指南** · 全部 · P0 · ✅ 已上线
- 每个游戏都有：学习目标、对应技能、等级说明、家长怎么教、生活中练习、达标表现、常见困难（`apps/web/js/guide.js`，单一来源）。
- 家长页：游戏名旁的 📖 打开指南；"🎯 需要加强"自动列出一次答对率 < 70% 的游戏和第一条教法。
- `npm run docs` 导出为 [`curriculum/parent-guide.md`](../../curriculum/parent-guide.md)；冒烟测试保证每个游戏都有指南。

**F-29 书写：描数字** · M11 · P0 · ✅ 已上线
- 因 Ethan 新出现的书写兴趣提前：Write Numbers 游戏，L1 1–5、L2 0–9、L3 10–20。

**F-27 健康时长守护** · 护栏 · P0
- 默认每次 15 分钟后：完成当前一局 → Dino 打哈欠 "Time for a break! Let's go play outside!" → 进入休息画面（给一条线下活动建议）[R2] §3、[R1-S27]。
- 家长可设每次 10 / 15 / 20 分钟、每日上限；家长面板显示每日分钟数。
- **不使用**倒计时、惩罚或"明天回来领奖"等设计 [R2] §2。

### 6.3 P1 —— v0.3「Smart Practice」

**F-30 学习者模型（按技能 Elo + 间隔复习）** · AI-A1 · **P0 · ✅ 已上线（第一版）**
- *实现*：`apps/web/js/learner.js`。按每个题目项记录次数、一次答对、Leitner 复习盒（1/2/4/7 天）；出题时先生成多道候选题，并优先挑出常错和到期复习的项目（实测常错项出现频率约为随机的 3 倍），其余题目保持混合。等级升降仍按一局的一次答对率。Elo 能力分留作下一步优化。
- 每个**技能项**（每个字母名 / 字母音、每个数字、每种题型）一个能力分；选题使预测答对率约 75% [R1-S37][R1-S8]。
- 间隔复习：答错或刚掌握的项在 1 / 3 / 7 天后混入，每局约 20–30% 是复习题 [R1-S43][R2-S4]。
- 现有 3 级等级保留为"展示层"（星星），内部由能力分驱动。
- *验收*：纯本地计算；有单元级测试（给定作答序列，能力分方向正确）；旧版 localStorage 数据自动迁移。

**F-31 家长掌握地图与学习报告** · AI-A1 · **P0 · ✅ 已上线**
- *实现*：家长页"📊 学习报告"——本周练习天数、分钟数、一次答对率及与上周对比、每日用时柱状图（超过 30 分钟标橙色）、字母名 / 字母音 / 数字 0–20 掌握地图、常错内容、规则生成的建议（含屏幕时间和入学清单提醒）。
- 26 个字母（名 / 音、大小写）+ 0–20 的热力图：已掌握 / 练习中 / 未开始；"常混淆对"（b/d、p/q、6/9、12/21）；按课程技能（E# / M#）而不是按游戏展示 [R2] 差距 #16、[R1] 建议 3。
- 每天一条"今天可以在生活中玩什么"的建议（规则生成，不调用 LLM）。

**F-32 Sound Builder（拼写 CVC）** · E7 · P1
- 听单词 → 用字母块拼出（cat = c-a-t）；字母块数量 = 单词长度 + 1–2 个干扰。

**F-33 Make 10（凑十 / 分解组合）** · M6 · P1
- 十格图里已有 6 个，"How many more to make 10?"；L1 凑 5，L2 凑 10，L3 分解 "7 is 4 and ?" [R2] 差距 #13。

**F-34 描红升级** · E9 · **P0**（因书写兴趣提前）
- 起笔点（绿点）+ 笔顺箭头；按笔画顺序判定；字母和数字都使用 **NSW Foundation Style** 字形。
- 先做小写字母（学校读物以小写为主）和 0–9。

**F-35 Dino Stories（个性化可解码小故事）** · E11 · AI-A2 · P1
- 离线用 LLM 生成、人工审核后打包的 4–6 句小故事，只用已学字母与 tricky words；主角名字在设备上替换 `<CHILD>`；逐词高亮朗读，孩子可点单词听读 [R1] 建议 5。
- 流程与评测：`ai/prompts/decodable-story.v1.md`、`ai/evals/decodable-story.md`、`ai/safety/guardrails.md`。
- *验收*：每个故事通过自动检查 + 人工评分 ≥ 4/5；首批 ≥ 20 篇，对应各字母组。

**F-36 奖励改造** · P1
- 贴纸改为**惊喜**：不预告、不显示"集齐全部"的号召，贴纸与"学会新技能"挂钩 [R3-S25][R2] 差距 #10。
- 表扬具体化："You learned the /m/ sound!"。
- 星星保留为进度反馈。

**F-37 离线 / PWA** · P1
- Service Worker 缓存全部资源和录音；manifest + 图标；自托管字体，去掉唯一的外部请求。

**F-38 陪玩卡片** · P1
- 每局结束后显示 1 条可选的亲子线下活动（"Find 3 things that start with /s/ at home"）[R2] 差距 #12、[R2-S36]。

### 6.4 P2 —— v0.4「Worlds」

**F-40 主题世界** · P2
- 首批 2 个：🦖 **Dino Land**（已有角色）和 🚗 **Beep Beep Town**（交通工具，数据最强的主题 [R3-S14]）；之后 🚀 Space、🌊 Ocean、🐶 Backyard。

## 7. AI 策略

**原则：AI 在幕后和家长侧工作；孩子端保持静态、安全、无对话；数据不离开设备。** 依据 [R1] 摘要 1–7。

| 阶段 | 能力 | 版本 | 孩子接触 LLM | 数据离开设备 |
|---|---|---|---|---|
| A1 | 学习者模型（Elo + 间隔复习）、掌握地图 | v0.3 | 否 | 否 |
| A2 | 离线 LLM 生成故事 / 题库 → 自动检查 → 人工审核 → 打包 | v0.3 | 否 | 否 |
| A3 | 预生成高质量 TTS 语音素材；phonics 音真人录音 | v0.2–0.3 | 否 | 否 |
| A4 | 设备端语音识别实验 | Exp | 否 | 否 |
| ✗ | 实时 LLM 对话 / AI 朋友 | 不做 | — | — |

**为什么不做 AI 聊天角色**：Common Sense Media 建议 5 岁及以下不使用 AI 陪伴玩具 [R1-S16]；实测发现护栏在长对话中失效 [R1-S15]；幼儿语音识别错误率高（幼儿园年龄段 WER 可达约 35%）[R1-S30]；澳洲 eSafety 与美国 FTC 正在调查 AI 陪伴产品 [R1-S19][R1-S22]；产品停服会给孩子造成情感伤害 [R1-S13]。

**AI 研发流程**：提示词版本化（`ai/prompts/`）→ 评测集（`ai/evals/`）→ 实验记录（`ai/experiments/`）→ 安全护栏（`ai/safety/`）。任何面向孩子的生成内容都必须人工审核。

### 8.1 入学标准：最低 / 典型 / 最高（NSW Kindergarten）

**标准体系**（[R4] §2）：
- **最低** = 入学时处于 *on track*。依据是 AEDC 的分界：高于第 25 百分位为 on track，低于第 10 百分位为发展脆弱 [R4-S24]，以及能完成 NSW Best Start 的基础任务 [R4-S3]。

| 学习记录（每项技能能力分、作答统计） | 设备 localStorage | 自适应、掌握地图 | 直到家长清空 |
| 使用时长（按天） | 设备 localStorage | 时长守护、家长面板 | 保留最近 90 天 |
| 星星、贴纸 | 设备 localStorage | 奖励 | 直到家长清空 |
| 录音 | **不保存**（F-50 实验也只在内存中识别） | — | — |

任何需要把数据发送出设备的功能（云同步、在线 LLM），都必须先写 ADR，更新隐私政策，取得家长同意，并完成合规评估（见 §11）。

## 13. 风险与对策

| 风险 | 可能性 | 影响 | 对策 |
|---|---|---|---|
| phonics 录音质量差或口音与学校不一致 | 中 | 高 | 先录 6 个音试玩；向学校确认 phonics 项目；必要时请配音员 |
| 孩子新鲜感下降、不想玩 | 高 | 高 | 主题世界、惊喜、Dino 成长；跟着孩子的兴趣问卷调整；不靠 dark pattern |
| 难度不合适导致沮丧 | 中 | 中 | F-26 逐级提示 + F-30 75% 目标答对率；监测沮丧事件 |
| 屏幕时间过长 | 低 | 中 | F-27 时长守护；家长设定上限 |
| 换设备 / 清浏览器数据导致进度丢失 | 中 | 中 | F-46 导出 / 导入；在家长页提示 |
| LLM 生成内容不当 | 低 | 高 | 只离线生成 + 自动检查 + 人工审核；不做实时生成 |
| 研究结论基于摘要、未读全文 | 中 | 中 | 关键决策（课程代码、指南数字）上线前核对原文（[`research/README.md`](../../research/README.md)） |
| 一人团队带宽有限 | 高 | 中 | 每个版本范围小；AI Agent 承担开发和文档；严格按优先级砍需求 |
