# ai/ — AI 研发

AI 在本产品中的定位（依据 `research/01-ai-solutions/`）：**AI 在幕后和家长侧工作，孩子端保持静态、安全、无对话**。

| 目录 | 内容 |
|---|---|
| [`safety/`](safety/) | 护栏规则：什么能做、什么不能做、生成内容如何审核 |
| [`prompts/`](prompts/) | 版本化的提示词（例如离线生成分级故事），每个提示词都对应一个评测集 |
| [`evals/`](evals/) | 评测集与评测标准：内容安全、适龄、可解码性、教学正确性 |
| [`experiments/`](experiments/) | 实验记录：假设 → 方法 → 结果 → 决定（例如 Elo vs 阈值、浏览器内语音识别） |

## AI 路线图（摘自 PRD-001 §7）
| 阶段 | 能力 | 孩子接触 LLM？ | 数据离开设备？ |

| A2 | 离线 LLM 生成个性化分级故事 / 题库，人工审核后打包 | 否 | 否 |
| A3 | 预生成高质量语音（TTS mp3），phonics 音真人录音 | 否 | 否 |
